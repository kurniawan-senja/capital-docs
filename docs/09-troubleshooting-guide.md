# 9. Troubleshooting Guide

## 9.1 Diagnostic Checklist

When a job fails, follow this sequence before investigating code:

1. Is the render method AfterFX.exe via evalFile? (Not nexrender)
2. Did the expression fail silently? Check log file in `C:/ae-automated/exports/`
3. Does the comp name match the exact 12-token format?
4. Are all dependencies available: comp SN, comp PER, CSV files, dropdown controls?
5. Only then investigate the JSX script or expression code

## 9.2 Common Issues

| Symptom | Likely Cause | Resolution |
| --- | --- | --- |
| Status stuck at PROCESSING | AE crashed or timed out | Check log file, restart AE, re-set status to READY |
| Blank video output | Expression throw or `footage()` mismatch | Check CSV name exact match, add fallback values |
| Comp not found error | Comp name token format mismatch | Verify all 12 tokens present in comp name |
| PRJ folder not found | Project structure changed | Verify `03_Source > PRJ` folder exists in project panel |
| Old RW not found | RW folder renamed or missing | Check RW folder starts with `RW_` in project panel |
| `render = FATAL` after 3 retries | Persistent AE or file error | Check Logs tab, fix root cause, reset retry_count to 0 |
| `file_link` empty after FINISHED | Drive upload failed | Check Drive credentials in n8n, verify folder ID |
| Export Comp path error | Script in `/test_src/` not `/scripts/` | Verify Execute Export Comp command path matches actual file location |

## 9.3 Log Files

Each JSX script writes a log file to `C:/ae-automated/exports/` on every run. Always check these first.

| Log File | Generated by |
| --- | --- |
| `render_{template_slug}.txt` | `Render.jsx` |
| `rw_update_{template_slug}.txt` | `Auto_Update_RW.jsx` |
| `log_{template_slug}.txt` | `Export_Comp.jsx` |
